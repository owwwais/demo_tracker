# TRACKER — موقع الديمو

موقع من صفحة واحدة يُري عميل TRACKER رحلة طرد كاملة بأربعة أدوار (المكتب، السائق، المرسل إليه، المالك) مع لوحة رسائل تحاكي ما يصل كل طرف. لا خادم ولا قاعدة بيانات ولا رسائل حقيقية: كل شيء في ذاكرة المتصفح ويزول بإعادة التحميل أو بزر «إعادة المشهد».

## التشغيل

```bash
npm install
npm run dev       # تطوير على http://localhost:5173
npm run build     # بناء ثابت في dist/
npm run preview   # معاينة البناء
```

النشر: ارفع مجلد `dist/` إلى Vercel أو Netlify أو Cloudflare Pages (موقع ثابت، لا إعدادات خاصة؛ التوجيه بالـhash فلا يحتاج قواعد إعادة توجيه).

## البنية

| المسار | المحتوى |
| --- | --- |
| `#/` | الرئيسية: البطل، المشكلة، رحلة الطرد في سبع خطوات، الأطراف الخمسة، الأسعار بتبديل المدة، الأسئلة، التذييل |
| `#/demo` | الديمو: شريط الخطوات التسع، مبدّل الأدوار، الشاشة، لوحة الرسائل |
| `src/demo/state.ts` | منطق السيناريو كاملًا (`useReducer`) ونصوص الرسائل |
| `src/demo/data.ts` | البيانات الوهمية والخطوات |
| `src/demo/views/` | لوحة المكتب، واجهة السائق، صفحة التتبع، لوحة المالك |

## التبعيات وتبريرها

- `react`, `vite`, `tailwindcss`: المقترح التقني في الموجز.
- `lucide-react`: مجموعة الأيقونات الموحدة المذكورة في الموجز.
- `qrcode.react`: رمز QR حقيقي قابل للمسح على الملصق، بلا طلب شبكة.
- `@fontsource/ibm-plex-sans-arabic`, `@fontsource/anton`: الخطوط مستضافة مع الموقع، فلا طلبات لـGoogle Fonts ويعمل الموقع دون اتصال بعد التحميل الأول.

## ما تم التحقق منه

- السيناريو التسع خطوات كاملًا (بالتأخير والاستبدال) آليًا بـPlaywright على 1440 و360 بكسل: بلا أخطاء، بلا تمرير أفقي، نحو 25 ثانية بالنقر الآلي.
- «إعادة المشهد» يعيد الخطوة 1 ويمسح الرسائل والشحنة.
- لا طلبات شبكة بعد التحميل الأول.
- LCP نحو 1.8 ثانية على 4G بطيئة مع إبطاء المعالج 4 مرات.

## يحتاج تأكيدًا قبل العرض

وثيقة الـPRD لم تكن بين يديّ، فهذه نصوص كتبتها لتكتمل الصفحة ويجب مطابقتها بها:

- **نصوص الرسائل** في `src/demo/state.ts`: يجب مطابقتها بجدول الإشعارات في القسم 9.
- **الأسعار** (149 / 299 / 599 ريال، وخصومات 5٪ و10٪ و20٪) وما تشمله كل باقة: أرقام نموذجية.
- **نصوص الرئيسية**: المشكلة في أربع بطاقات، الخطوات السبع، الأطراف الخمسة، الأسئلة الشائعة.
- **أرقام لوحة المالك** وأسماء المكاتب الأخرى والسائقين الإضافيين (ماجد، سعد، والسائق البديل سالم): وهمية.
- **الصور الثلاث** مولّدة بالذكاء الاصطناعي (Higgsfield)، لا تُظهر علامة تجارية، وليست صورًا للعميل.

## ما أقلقني ولم يكن في الطلب

رمز الاستلام في الديمو يظهر في لوحة الرسائل وفي صفحة التتبع معًا ليسهل العرض. في النظام الحقيقي يجب ألا يظهر الرمز في صفحة التتبع العامة لأن رابطها يصل المرسل أيضًا، وإلا فقد الرمز معناه كإثبات أن المرسل إليه نفسه استلم.
